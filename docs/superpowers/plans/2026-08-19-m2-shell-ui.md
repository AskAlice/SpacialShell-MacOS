# SpacialShell M2 Implementation Plan — Shell UI, IPC/CLI, Raycast

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the headless M1 core its material-shell face (left rail + top bar + focus glow + Zen + drag), a control surface (unix-socket IPC + `spacialctl`), and a Raycast extension — without changing the spatial model's semantics.

**Architecture:** New leaf target `SpacialShellProtocol` (wire types, `ShellSnapshot`, NDJSON codec) under Kit; Kit gains payload verbs on `Command`, `CommandOutcome` errors, `World.zen`, `ShellInsets`, and a `WorldStore` that publishes `(World, ShellSnapshot)`; `SpacialShellIPC` serves the socket; `SpacialCtl`/`spacialctl` is a thin client; `SpacialShellUI` draws non-activating `NSPanel`s from the snapshot; `raycast/` shells out to `spacialctl --json`.

**Tech Stack:** Swift 6 / SwiftPM (macOS 14+), AppKit + SwiftUI (NSHostingView), Network.framework (AF_UNIX), Swift Testing; TypeScript + `@raycast/api` 1.104 / `@raycast/utils` 2.3, vitest.

**Spec:** `docs/superpowers/specs/2026-08-19-m2-shell-ui-design.md` (decisions + design system — binding). **Appendices with full code-level detail:** A panels `docs/superpowers/plans/2026-08-19-m2-appendix-a-panels.md`, B IPC/CLI/verbs `…-appendix-b-ipc-cli.md`, C Raycast `…-appendix-c-raycast.md`. **Research notes (verified platform facts):** `docs/superpowers/specs/2026-08-19-m2-research-notes.md`. Where an appendix disagrees with the spec's Decisions table or with a task's "Rulings" line below, **the spec/ruling wins**.

## Global Constraints

- Swift tools 6.0, `platforms: [.macOS(.v14)]`, strict concurrency, **warning-free** builds; Swift Testing (`#expect(struct.mutating())` doesn't compile — bind to a `let` first); M1 suite (119 tests) must stay green at every commit.
- Dependencies point downward: `SpacialShellProtocol` (Foundation only) ← `SpacialShellKit` (Foundation+CoreGraphics+TOMLDecoder) ← `SpacialShellPlatform`, `SpacialShellIPC`, `SpacialShellUI` (AppKit/SwiftUI allowed; **no ApplicationServices/AX in UI**) ← `SpacialShell` app; `SpacialCtl`/`spacialctl` depend on `SpacialShellProtocol` only.
- Verbs extend `Command` with **distinct base names** (never overloaded case names — they break pattern matching on this toolchain): `focusWorkspaceID(UUID)`, `focusWindowRef(WindowRef)`, `closeWindowRef(WindowRef)`, `moveWindowToWorkspaceID(WindowRef, UUID)`, `moveWindowToIndex(WindowRef, Int)`, `renameWorkspace(UUID, String)`, `setWorkspaceSymbol(UUID, String)`, `setLayout(Layout)`, `setWorkspaceLayout(UUID, Layout)`, `addWorkspace(display: DisplayID, name: String?, pinned: Bool)`, `removeWorkspace(UUID)`, `pinWorkspace(UUID, Bool)`. `toggleShellUI` flips `World.zen`.
- Every new verb ends in `normalize()` and is covered by the property test; `World.invariantViolations().isEmpty` after every command.
- Wire: `RectDTO{x,y,width,height}` never bare CGRect; NDJSON lines; `IPCProtocol.version = 1`; max request 64 KiB; socket `~/Library/Application Support/SpacialShell/spacialshell.sock` (dir 0700, file 0600), fallback `/tmp/spacialshell-<uid>.sock` when > 103 bytes.
- Panels: `NSPanel` `[.borderless,.nonactivatingPanel]`, `canBecomeKey/Main=false`, `isOpaque=false`, `backgroundColor=.clear`, `hasShadow=false`, **`isMovable=false`** (default is TRUE for this mask — measured), `isMovableByWindowBackground=false`, `hidesOnDeactivate=false`, `acceptsMouseMovedEvents=true`, `becomesKeyOnlyIfNeeded=true`, `level = NSWindow.Level(rawValue: Int(CGWindowLevelForKey(.utilityWindow)))` (=19: above normal/floating/modal app windows, below Dock/menu bar/menus), `collectionBehavior [.canJoinAllSpaces,.stationary,.ignoresCycle,.fullScreenNone]`, `NSVisualEffectView(material, .behindWindow, state: .active)` + `NSHostingView` (wantsLayer, clear layer, `sizingOptions = []`, no `.background(Material)` in SwiftUI). Highlight panel additionally `ignoresMouseEvents = true`.
- Config paths/keys per spec; docs make no unverified claims; attribution header rule for any lifted code (`// Adapted from AeroSpace (MIT) — <path> @ c548c7f` + NOTICE).
- Commit per task with the message given; run `swift build` + the focused tests before each commit; the full `swift test` before the last commit of each group.
