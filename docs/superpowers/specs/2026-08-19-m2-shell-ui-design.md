# SpacialShell M2 — Shell UI, control surface, Raycast

## Context

M1 (merged to `main`, installed at `/Applications/SpacialShell.app`, running with the Accessibility grant) is the headless spatial core: per-screen workspace stacks, five layouts, corner-sliver parking, Fn hotkeys. It has no visible identity — Alice's reaction was "where is the UI?". M2 gives SpacialShell the **material-shell silhouette she asked for (faithful to the GNOME extension, Apple materials underneath)**, a transient highlight border when things tile, a real Zen toggle, drag-to-reorder, and a control surface — unix-socket IPC + `spacialctl` CLI — so a **Raycast extension** (Switch, Move Window To…, Manage Workspaces, menu-bar + hotkey-able no-view commands) can drive it. Reference: material-shell.com + Alice's screenshot — left *system panel* (search glyph, workspace icons, `+`, tray + stacked clock), top *workspace panel* (tabs icon·title·×, `+` tab, layout switcher). Themes/blur collapse into vibrancy + system accent + auto appearance.

The spatial model's semantics don't change; M2 adds *verbs*, a published *snapshot*, *insets*, and consumers.

## Design system (frontend-design pass)

**Subject/job:** chrome for someone who lives in it 8 h/day. Show *where you are* (workspace · window · layout), let them change it in one click, then get out of the way. Restraint everywhere; the one moment of drama is the **focus glow that lands on the tile** (Alice's explicit ask; also what makes tiling legible).

- **Colour:** no palette of our own. Rail = `NSVisualEffectView(.sidebar)`, top bar = `.headerView`, `blendingMode .behindWindow`, **`state = .active`**; active workspace/tab = `controlAccentColor` (18 % fill on the rounded square, glyph/text at 100 %); inactive `secondaryLabelColor`; hover `quaternaryLabelColor`; hairlines `separatorColor`; highlight stroke = accent, fallback `#0A84FF` (the only hex in the target). Light/dark/accent come from the OS ("Primary theme" = System Settings accent).
- **Type:** SF Pro 12 pt tab titles, 12 pt medium hover labels, 11 pt tooltips, "+N" badge 9 pt semibold rounded; clock 11 pt medium **monospaced**, HH over MM (as in the reference "17 / 33").
- **Layout:** 8 pt grid. Rail **48 pt** (`panel-width`): 32 pt tiles, radius 8, 8 pt gaps, 16 pt between groups (search · workspaces+`+` · clock+menu). Top bar **34 pt** (`panel-height`): 26 pt tabs, radius 6, icon 16 pt, 10 pt h-padding, tab width 88–220; layout switcher 24 pt glyph 12 pt from the trailing edge; badge offset (+7,−7). Panels flush to screen edges.
- **Icons (SF Symbols):** search `magnifyingglass`, add `plus`, app menu `square.stack.3d.up`; layouts `rectangle` · `rectangle.split.2x1` · `rectangle.split.3x1` · `sidebar.left` (half) · `square.grid.2x2`; workspace = its `symbol`, or the first app's icon when the symbol is the default and the workspace has windows (material-shell's category-from-content); tabs = `NSRunningApplication.icon`.
- **Motion:** the glow: 3 pt accent stroke at the *desired* frame (from the reconciler — it lands before the AX write does), scale 1.06→1 / opacity 0→1 spring 180 ms, hold, fade over `highlight-ms` (600); Zen: panels fade 180 ms; reduce-motion → instant; `highlight-ms = 0` schedules nothing.
- **Copy:** sentence case; verbs on controls ("Rename workspace…", "Remove workspace", "Toggle Zen"); empty states direct ("No windows here yet — open an app or press Fn+⇧S on a window above"). Raycast: Title Case command names (store rule), sentence case elsewhere.
- **Self-critique vs brief:** we keep the search glyph (opens Raycast — the honest macOS "overview") and the stacked clock (cheap, faithful, delightful); we **drop the system tray** (macOS's menu bar is one; a documented `SystemTraySlot` marks the gap); themes aren't reimplemented. Nothing here is a generic default — the OS material *is* the palette.

### Amendment 2026-09-24 — fullscreen focus protection (#28)

macOS gives a window manager no veto over an app activating itself, so protection is reactive: the store sees the grab, undoes it, and puts the fullscreen window back.

- **Human input.** The hotkey `CGEventTap`'s every keyDown (⌘Tab included) and the global left-mouse-down monitor report `BackendEvent.humanInput` through the backend's event stream, so it always arrives ahead of the activation it causes. The store stamps it on arrival. An activation or focus change within `WorldStore.humanInputWindow` (**1 s**) of one is the user's and goes through exactly as before. No config key.
- **When it applies.** Only while the model's focused window is fullscreen. `AXFullScreen` alone is never trusted — a window keeps it after the user leaves its Space — but model focus follows every native focus report, so it stops naming that window the moment the user goes elsewhere. Our own raises' echoes, the fullscreen app's own activation, the shell's own process, and windows the model does not manage are never intrusions.
- **Move vs defer.** A tiled or floating requester moves into the **active workspace** of a display not showing a fullscreen Space (its own display if that qualifies), as a new window would land. "Not showing fullscreen" for a display the user is not on means its active workspace's anchor is not a fullscreen window; a stale anchor errs towards *covered*, i.e. towards deferring. With no such display (one display, or all fullscreen), or for an ephemeral requester, the request is **deferred**. Either way model focus returns to the fullscreen window and it is raised again.
- **Deferred queue.** Oldest first, one entry per requester, each remembering the fullscreen window it waits behind. When that window leaves fullscreen or goes away, the newest request whose window still exists is focused — if the user is still on the window fullscreen ended in; if they have gone elsewhere, the requests are dropped (the windows keep their tabs).
- **Known gaps (verify live).** A trackpad swipe between Spaces is neither a keyDown nor a mouse down, so swiping out of fullscreen may read as an intrusion; adding gesture/scroll events to the monitor is the fix if it does. An app that re-activates itself whenever it loses focus trades places with the fullscreen window for as long as it keeps trying.

## Architecture

### A. Protocol + Kit (pure; unit-tested)
- **`SpacialShellProtocol`** (new leaf): move `DisplayID`, `WindowID`, `WindowRef`, `Layout` out of `Model.swift` (typealias shims in Kit; fix `import struct SpacialShellKit.WindowRef` in AppRuntime); `RectDTO`; `ShellSnapshot` (below); `JSONValue`; `IPCProtocol {version=1, maxRequestBytes=64K, defaultSocketPath()}`; `IPCRequest {id,cmd,args}`, `IPCResponse {id,v,ok,data,error}`, `IPCEvent {v,event,data}`; `LineFramer` (chunk → lines / overflow); `IPCCodec` (sortedKeys, never prettyPrinted).
- **`ShellSnapshot`** (Codable/Sendable/Equatable): `v`, `generation`, `capabilities: [String]` (`["workspace-crud","zen","symbols"]`), `screens: [ScreenRow {display, frame: RectDTO?, visibleFrame: RectDTO?, isMain, isFocused, isCoveredByFullscreen, insets: EdgeInsetsDTO, activeWorkspaceId, workspaces: [WorkspaceRow {id,name,symbol,layout,pinned,isActive,windowCount,isTrailingEmpty}], windows: [WindowRow {window: WindowRef, pid, workspaceId: UUID?, title, appName, bundleID, isFocused, isVisibleUnderLayout, isFloating, isHidden}]}]`, `focus {screen, window}`, `focusedFrame: RectDTO?`, `zen`, `locked`, `chrome {panelWidth,panelHeight,railSide,highlightMs,launcherURL,showPanels}`; `isEquivalent(to:)` ignores `generation`. `isVisibleUnderLayout` = pure `LayoutEngine.frames(...)[i] != nil` (unit rect) so it's right mid-hot-plug.
- **`Config`**: `RailSide`; `panel-width` 48, `panel-height` 34, `rail-side`, `highlight-ms` 600, `launcher-url` "raycast://", `show-panels` true.
- **`Geometry.flip(_:mainHeight:)`** (Kit; `DisplayTopology.flip` forwards) + **`ShellInsets`** (`init(config:hidden:)`, `apply(to:)`).
- **`Reconciler.desired(… insets: [DisplayID: ShellInsets] = [:], suspended: Set<WindowRef> = [])`**.
- **`Command`** new cases (above) + `closeWindowRef(WindowRef)`; `CommandError {unknownWorkspace, unknownWindow, unknownScreen, notApplicable(String), locked}`; `CommandOutcome`; `World.zen` (init default false); `Workspace.defaultSymbol`; `WindowSnapshot.appName` (Platform fills from `NSRunningApplication.localizedName`).
- **`WorldStore`**: `onChange(World, ShellSnapshot)`; tables `titles`, `appNames` (cleared with `bundleIDs`), `fullscreenDisplays`; `run(_:) -> CommandReport` (skip reconcile on error); `reconcile()` → insets from `world.zen`/config → `publish(desired:)` (dedupe) — also publish on lock/unlock; `shellSnapshot()`, `windowRows(workspace:)`, `suspend(_:)`. `PersistedState.zen` (decodeIfPresent ?? false; version stays 1).

### B. IPC + CLI
- **`SpacialShellIPC`**: `IPCServer(store:options:reloadConfig:)` — `start() async throws` (path-length guard, 0700 dir, probe-before-unlink, listener `.ready` → chmod 0600, `maxConnections` 16), `stop()` sync (cancel + unlink), `nonisolated publish(_:)`; `IPCConnection` actor pull-driven pump (next receive after previous write; overflow → error + close); `SnapshotHub` single-slot coalescing mailbox per subscriber, `generation`-guarded, `sendTimeout` 10 s cancels wedged subscribers; `IPCDispatch.handle(_:) -> .response|.subscribe` with the command table: `version, state, list-screens, list-workspaces [screen], list-windows [workspace], focus-workspace {id|index(+screen)|name}, focus-window {id,pid}, move-window {window?, to-workspace|to-screen|to-index}, add-workspace {screen?,name?,pinned?} → {id}, rename-workspace, set-symbol, set-layout {id?,layout}, pin-workspace, remove-workspace, cycle-layout, toggle-zen → {zen}, run {command|list:true}, reload-config, subscribe`. Errors: `ok:false` + human message, never a crash (typed `JSONValue` accessors). Treat `NWConnection` `.waiting` as terminal (dead socket) — in the probe and the client.
- **`SpacialCtl` lib + `spacialctl` exe**: hand-rolled `CLIParser.parse(argv) -> .invocation|.help|.usageError`; subcommands = wire `cmd` names; `--json` default for `state`/`list-*`, `--no-json` for tables; `--window id:pid` or `--id/--pid`; `Render.table`; `IPCClient` (2 s connect timeout, `.waiting`==failed); `SpacialCtl.run(arguments:out:err:) async -> ExitCode {0 ok,1 daemon,2 usage,3 cannotConnect}`; `subscribe` prints NDJSON + `fflush`; `main.swift` = 4 lines. Bundle: `Scripts/bundle.sh` copies to `Contents/MacOS/spacialctl` and **signs the helper first**, then the bundle. `Paths.socketFile` = `IPCProtocol.defaultSocketPath()`.
- **AppRuntime**: `SnapshotPublisher` box breaks the store↔server init cycle; server starts after `store.start()` (failure never fails boot); `TerminationGate.arm(server:)`, `server.stop()` right after `tap.stop()`; `reloadConfig` exposed to the dispatcher via `MainActor.run`.

## Risks (macOS 26 / Network.framework / Raycast — mitigations are in the tasks)
Vibrancy flat grey unless `state=.active` · black panel unless `isOpaque=false` **and** `backgroundColor=.clear` · SwiftUI opaque bg over material (clear hosting layer) · hover sticks across screen edges (`NSTrackingArea`) · panels over fullscreen/lock (`orderOut`) · wrong display after hot-plug (`mainHeight` fallback + `panel.screen` assert) · double gap at rail edge (inset-before-gap test) · click-eating highlight panel (`ignoresMouseEvents` assert) · hotkeys dying from mouse traffic (separate `DragTap`) · `NWConnection .waiting` ≠ `.failed` · chmod before `.ready` is ENOENT · `NWListener.cancel()` doesn't unlink · `EADDRINUSE` arrives via state handler · sun_path 104 · subscribe back-pressure (single-slot mailbox + sendTimeout) · dedupe publishes · overloaded enum case names break matching · `#expect(mutating)` quirk · Raycast: minimal `PATH`, `err.code` number-vs-"ENOENT", implicit focused-window target, menu-bar `interval` min 1m, `ray build` may need a token in CI, store: no bundled binaries, custom icon required.
