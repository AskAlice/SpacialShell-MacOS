# M3 roadmap — proposal

Date: 2026-08-25. Input: `2026-08-25-de-gap-analysis.md`. This reshapes M3 from "persistence
only" (the M1 spec's milestone table) into three waves ordered by trust: first make the core's
promise true at the edges, then make the shell self-explanatory, then make every surface honest.
Task numbers T6–T24 refer to `2026-08-19-m2-shell-ui-design.md`; its rulings stay binding.
Window↔placeholder matching (the original M3) moves to wave M3b where its prerequisites live.

## M3a — trustworthy core: invariant I6, "no invisible windows"

**New invariant I6** (joins I1–I5 in the model spec): *every window that is neither minimized,
hidden by its app, nor on an inactive workspace is visible on screen — and every window the shell
lists is reachable by one click or command.* Corollary (Alice's phrasing): switching to an app
always shows a window.

| # | Task | Sketch |
|---|---|---|
| A1 | `invariantViolations()` learns I6 + a property test | Random worlds + layouts through `Reconciler.desired`; assert every active-workspace, non-hidden window gets a `.frame` inside its display, or is `parked` only when the layout defines that (maximize/split overflow — which the tab bar shows). |
| A2 | Minimum-size clamp in `LayoutEngine` | `columns/rows` floor at (120 × 80) pt; past that, overflow windows park (they keep tabs). Kills zero/negative frames. |
| A3 | Backend verb `setMinimized(_:Bool)` | AX `kAXMinimizedAttribute`. Clicking a dimmed tab deminiaturizes then focuses (replaces today's dead click); `focusWindowRef` on a hidden ref stops being a no-op. |
| A4 | Rescue path for retirees | Retired-while-parked windows (`ignored` after 3 failed writes) get: their pre-park frame restored at retirement time (not only at quit), a periodic re-adoption probe, and a `rescue-windows` command (spec §13.3) wired to IPC and the shell menu. |
| A5 | Fullscreen keeps identity | Fullscreen windows stay in their workspace flagged `fullscreen` instead of moving to `ignored`: tab stays (badged), `Fn+A/D` skips it, focus command raises it (macOS brings its Space). |
| A6 | Model "on another Space" | `WindowSnapshot.onActiveSpace`; off-Space windows are `.untouched` (no phantom writes) and badged in tabs. `activeSpaceDidChange` re-adopts. |
| A7 | Activation surfacing | `didActivateApplicationNotification` triggers an immediate targeted focus resolve for the activated pid (not just the debounced full refresh), so ⌘Tab/Dock lands on a visible window fast; drop the mouse-down refresh suppression for this path. |

Exit test: the I6 property suite green; manual: ⌘Tab through 10 apps under every layout — a
window is on screen within one reconcile every time.

## M3c — config truth & polish

- Remove-or-implement sweep stays enforced by AGENTS.md's "no placeholder" bar: `theme`/`font`/
  `icon-set` removed (done on the PR-3 branch), `highlight-*` implemented by B6, `start-at-login`
  implemented in M4 as planned or removed from parsing until then.
- Unknown config keys warn instead of hard-rejecting the file (a typo must not disarm reload);
  `[[ephemeral]]`-replacement gotcha documented inline in the example config.
- Sheets attach to their owner visually (no peer tab), keyboard-window adoption fast path,
  accessory-app adoption behind a config list.
- T24 testing checklist additions + snapshot-story coverage for every new surface.

## Sequencing and gates

M3a first — it is small, mostly Kit-pure, and everything else builds trust on it. B2 unblocks
titles everywhere and is the largest single item; B3–B5 are independent of it. Each task lands as
one PR with the AGENTS.md media rule (screenshots + change/overview animations) and `swift test`
counts; M3a exit test gates the milestone.
